## RFP602 分压

RFP602 是个压敏电阻，受压越大阻值越小。要转成电压给 ADC，得串一个固定电阻分压：

```
3V3 ──[ RFP602 ]──┬── GPIO2
                  │
                [ 10kΩ ]
                  │
                 GND
```

压力增大 → RFP602 阻值下降 → GPIO2 的电压上升 → ADC 读数变大。所以空槽读数低、满槽读数高。

买的是三针模块版（VCC / GND / AO）的话，板上已经带了这个电阻，直接接就行。

## 为什么这么选脚

这块板子的引脚基本被摄像头占完了，留给传感器的其实很少，有两条硬限制：

**一、开 WiFi 之后 ADC2 不能用。** ESP32-S3 的 ADC2（GPIO11~20）被 WiFi 驱动占用，只要连着 WiFi 就读不出正确值。所以模拟量只能走 ADC1，也就是 GPIO1~10。而摄像头的 D0~D7、PCLK、VSYNC、HREF、SIOD、SIOC 把 4~10 都占了，剩下能用的只有 1、2、3。

土壤占 1、光敏占 3，最后一个 2 号留给了饲料槽的压力膜——原来接在 2 号上的二氧化碳只能让位。二氧化碳走的是串口，串口可以挂在任意 GPIO 上，所以挪到了空闲的 14 号。

**二、GPIO48 是板载 WS2812 彩灯。** 不少教程会建议用 48，但这块板子上它接着灯珠的数据脚。把串口接收挂上去，灯会乱闪，数据也不稳。同理 19/20 是 USB、43/44 是下载串口、26~32 是 Flash 和 PSRAM，都不能动。

| GPIO | 用途 |
|------|------|
| 1 / 2 / 3 | 土壤 / 饲料槽 / 光敏（ADC1，唯一能用的三个） |
| 4~10 | 摄像头 |
| 11~13、15~18 | 摄像头 |
| 14 | 二氧化碳串口 |
| 21 | 火焰 |
| 41 / 42 | OLED I2C |
| 47 | DHT11 |
| 48 | 板载 WS2812，勿用 |
| 19 / 20 | USB，勿用 |
| 26~32 | Flash / PSRAM，勿用 |
| 38~40 | 板载 TF 卡座，不用 SD 时可借用 |

## 供电

整套用 USB 供电就够，但有两个地方要注意：

- JW01 必须 5V。板上 5V 引脚从 USB 直接过来，可以带。
- 摄像头和 WiFi 同时工作峰值电流会到 300mA 左右，USB 线太细或者用充电宝会掉压重启。表现是串口反复打印启动信息。

## 传感器标定

### RFP602（饲料槽）

出厂没有标定值，第一次用要先标：

```
1. 把料槽清空        → 串口发 t 回车
2. 装满正常一槽料    → 串口发 f 回车
3. 想核对就发 r      → 打印原始值、标定值、当前百分比
4. 换槽或重装后重来  → 先发 c 清除，再 t / f
```

标定值写进 NVS，断电不丢。没标定之前固件不会上报 `feed_level`，网页上显示“等待传感器数据”，不会拿悬空引脚的随机数糊弄。

### 土壤湿度

固件里 `SOIL_DRY` / `SOIL_WET` 两个宏是原始 ADC 值的两端，默认 3200 / 1400，会按比例映射成 0~100%。换了探头或者插的深度不同，最好自己测一下：探头完全泡水里记一个值，晾干再记一个值，填进去。

### 二氧化碳

JW01 输出 6 字节帧，格式 `2C HH LL X Y CK`，前 5 字节求和取低 8 位等于第 6 字节。固件按这个校验，校验不过就丢掉这一帧。串口上看到 `[JW01] 2C ...` 说明收到帧了，一直不打印就是线没接好或者模块没供电。
