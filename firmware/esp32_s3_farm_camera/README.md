# 终端固件

`esp32_s3_farm_camera.ino`，单文件，Arduino 框架。

## 编译

Arduino IDE 里打开本目录的 `.ino`（目录名必须和文件名一致，否则 IDE 不认）。

| 选项 | 值 |
|------|-----|
| 开发板 | ESP32S3 Dev Module |
| PSRAM | **OPI PSRAM** |
| Flash Size | 16MB |
| Partition Scheme | 默认 3MB APP |
| 端口 | 板子对应的 COM |

PSRAM 一定要选 OPI，选错摄像头初始化会直接失败，报 `0x105` / `0x106`。

依赖库：DHT sensor library、Adafruit Unified Sensor、Adafruit SSD1306、Adafruit GFX Library。esp32-camera 随 ESP32 Arduino 核心自带，不用单独装。

## 烧录前要改的

文件开头几行：

```cpp
const char* ssid      = "你的WiFi";
const char* password  = "你的密码";
const char* serverUrl = "http://服务器IP:3000/api/data";
const char* camUrl    = "http://服务器IP:3000/api/camera/esp32-01";
const char* DEVICE_ID = "esp32-01";
const char* DEVICE_NAME = "1号鸡舍";
```

`DEVICE_ID` 要和网站上设备列表里的一致，否则会当成新设备。`DEVICE_NAME` 只是首次创建时的默认名，用户在网页上改过之后就以网页为准。

## 引脚

| 模块 | 引脚 |
|------|------|
| DHT11 DATA | GPIO47 |
| 土壤 AO | GPIO1 |
| 光敏 AO | GPIO3 |
| 火焰 DO | GPIO21 |
| JW01 二氧化碳 B(TX) | GPIO14 |
| RFP602 AO | GPIO2 |
| OLED SDA / SCL | GPIO41 / GPIO42 |
| 摄像头 | 板载，固定 |

为什么是这几个脚、以及为什么不能用 GPIO48，见 [`../docs/hardware.md`](../docs/hardware.md)。

## 运行时行为

主循环四个节奏：

| 周期 | 做什么 |
|------|--------|
| 1 秒 | 读传感器、HTTP 上报 |
| 1 秒 | 有浏览器在拉流时跳过快照，否则抓一帧上传 |
| 3 秒 | OLED 翻页（温湿度 / 土壤+CO2+光照+饲料 / 火焰+摄像头+WiFi） |
| 随时 | 处理串口标定命令 |

DHT11 是单独的 2.5 秒节奏。手册写的两次读取间隔要 ≥2 秒，按 1 秒读会连续超时——读失败时代码会重试 3 次，还不行就保留上一次的有效值，连续失败 6 次才判定传感器掉线，这时上报里不带温湿度字段，网页显示“—”。

串口日志长这样：

```
T=24.5C H=62% | soil=812 co2=780 light=1560 | flame=1 | feed=48%(1420)
[环境] HTTP 200
[摄像头] HTTP 200
```

中文在部分串口工具里会显示成问号，那是工具编码的问题，不影响功能。

## 标定命令

串口监视器（115200，加换行符）里直接敲：

| 命令 | 作用 |
|------|------|
| `t` | 空槽标定：记下当前值作为 0% |
| `f` | 满槽标定：记下当前值作为 100% |
| `r` | 打印原始值、标定值、当前百分比 |
| `c` | 清除标定 |

`t` 和 `f` 都要做过一次才会生效，标定值写进 NVS，断电重烧都不会丢（除非全片擦除）。

先 `c` 再 `t`、`f` 可以重来。换了料槽或者重新装了传感器就要重标。

## 视频流

板子连上 WiFi 后会在 81 端口起一个 MJPEG 服务：

```
http://<板子IP>:81/stream
```

地址和 IP 会打印在串口里。同一个局域网内浏览器直接打开就行，延迟很低；外网访问走服务器上的快照（每秒一张）。

网页打开设备详情时会优先尝试直连这个流，5 秒内没画面就自动退回快照，所以不在同一局域网也不会白屏。

## 常见问题

**摄像头初始化失败 `0x105`/`0x106`**
PSRAM 没选 OPI，或者 FPC 排线没插到底。排线要轻轻推到底再压卡扣。

**反复重启**
供电不足。WiFi + 摄像头峰值电流 300mA 左右，换根粗一点的 USB 线，别用充电宝。

**温度读不到但 OLED 有数字**
OLED 显示的是上一次成功读取的缓存值，不代表当前读到了。看串口有没有 `T=` 那行。

**二氧化碳一直是 0**
串口上没有 `[JW01] 2C ...` 说明没收到帧。先确认模块是 5V 供电，再确认 B 线接在 GPIO14 上接牢了。JW01 的 A/B 是 TTL 串口不是 RS485，A 不用接。

**饲料槽一直显示“等待传感器数据”**
没标定。按上面发 `t` 和 `f`。标定过还不行就发 `r` 看原始值有没有随压力变化——不变的话是分压电阻没接或者传感器没压到。
